# Face detection models

`face_detection_yunet_2023mar.onnx` is YuNet, a small neural-network face detector
from the OpenCV model zoo (https://github.com/opencv/opencv_zoo, models/face_detection_yunet).
MIT License, Copyright (c) 2020 Shiqi Yu. OpenCV runs it with `cv2.FaceDetectorYN`;
no extra packages are needed.
